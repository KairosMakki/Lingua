# Compatibility Matrix

| Format | Windows | Linux | macOS |
|--------|---------|-------|-------|
| PE | Full | Inspect + Wine adapter | Inspect + Wine adapter |
| ELF | Inspect | Full | Inspect |
| .deb | Inspect/Extract | Full | Inspect/Extract |
| AppImage | Inspect | Inspect/Run | Inspect |
